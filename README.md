# XPERIENCE

Aplikasi kamera profesional Android (Kotlin · Jetpack Compose · CameraX + Camera2) dengan pengalaman gaya Photo Pro.

- Mod **AUTO / P / S / M / MR** (Memory Recall MR1–MR3)
- Dail Shutter (1/8000 – 30"), ISO, EV, White Balance + Custom Kelvin (2500–10000K)
- AF-S / AF-C / MF + focus peaking + magnifier ×3, AEL, AF-ON
- Meter Multi / Center / Spot / Highlight, histogram, zebra, amaran bayang, aras elektronik, grid
- Pemilih kanta 16 / 24 / 48 / 70mm (dikesan dari perkakasan), zum cubit
- JPEG / RAW (DNG) / RAW+JPEG, 4:3 / 16:9 / 1:1, Drive: Single, Continuous, Hi-Speed, Timer, Interval
- Creative Look (ST, NT, VV, FL, IN, SH…), koleksi Leica-inspired, Harcourt Studio, Film, B&W
- AI Bokeh (depth map dalam peranti, f/1.0 – f/11), DRO
- Galeri dengan EXIF + editor Look/Bokeh
- Semak kemas kini automatik dari GitHub Releases
